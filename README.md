# Bean There — лендинг кофейни

Одностраничный адаптивный лендинг вымышленной кофейни «Bean There».

## Стек

- HTML5 (семантическая разметка)
- CSS3: переменные, Grid, Flexbox, mobile-first, брейкпоинты 768px и 1200px
- Vanilla JS: только бургер-меню
- Без фреймворков и библиотек

## Что реализовано

- Липкая шапка, бургер-меню на весь экран на мобильных (< 768px)
- Hero-блок с затемнением фона
- Секция «О нас» в две колонки с преимуществами
- Меню: CSS Grid, 1 / 2 / 3 колонки, hover-эффект на карточках
- Отзывы, футер с контактами, часами работы и соцсетями
- Плавный скролл к секциям через CSS `scroll-behavior`
- Доступность: `alt` у всех изображений, `aria-*` у бургера, закрытие меню по Esc, поддержка `prefers-reduced-motion`
- Корректное отображение от 320px

## Структура

```
├── index.html

```

## Запуск

Откройте `index.html` в браузере, сборка не нужна.

Фотографии: [Unsplash](https://unsplash.com). Шрифты: Playfair Display и Inter (Google Fonts).
